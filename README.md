# Calculator AI Demo

Demo project with agent skills and in-repo documentation.

## Wiki

Product, process, and engineering docs are published as a browsable wiki:

**[https://irenadimitrova1.github.io/calculator-ai-demo/](https://irenadimitrova1.github.io/calculator-ai-demo/)**

PMs and POs can edit pages via the **Edit this page** button on the live site — no Git CLI required. See [docs/contributing.md](docs/contributing.md).

## Local preview

```bash
pip install -r requirements.txt
mkdocs serve
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000).
