# React + Vite + TypeScript for the calculator app

The calculator PoC is greenfield with no existing app code. We chose React + Vite + TypeScript over plain HTML/CSS/JS. Vite gives a fast dev preview and production build; React and TypeScript scale into v1/v2 (scientific mode, stateful UX) without a rewrite. Plain HTML was rejected because later features would likely force a framework migration anyway.
